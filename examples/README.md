# Examples

## Quick Start Examples

- **test_tools.py** - Comprehensive test suite for all core tools
- **test_all_features.py** - Test all features including new tools

## Agent Examples

- **zhipu_agent.py** - Complete workflow with ZhipuAI GLM-4-flash
- **openrouter_agent.py** - Complete workflow with OpenRouter free models
- **simple_agent_unified.py** - Unified agent supporting multiple LLM providers

## Basic Examples

- **simple_serp.py** - Basic SERP search
- **simple_scrape.py** - Basic web scraping
- **simple_markdown.py** - Markdown conversion
- **batch_example.py** - Batch operations

## Usage

```bash
# Test all tools
python examples/test_tools.py

# Run agent demo
python examples/zhipu_agent.py
python examples/openrouter_agent.py

# Run basic examples
python examples/simple_serp.py
```
